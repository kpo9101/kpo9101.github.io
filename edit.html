GitHub 저장 설정

처음 한 번만 하면 됩니다. 토큰은 이 브라우저에만 저장되고 다른 곳으로 보내지지 않습니다(GitHub 저장 요청에만 쓰입니다).

  1. GitHub 토큰 만들기 화면을 엽니다 (kpo9101로 로그인된 상태).
  2. Token name: portfolio-editor, Expiration: 원하는 기간을 고릅니다.
  3. Repository access: Only select repositories → kpo9101.github.io 하나만 선택합니다.
  4. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
  5. 맨 아래 Generate token을 누르고, 나온 토큰을 복사해 아래 칸에 붙여넣습니다.
